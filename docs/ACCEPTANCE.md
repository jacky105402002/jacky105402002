# GitHub 個人首頁驗收規範

以下為開發後需執行的驗收條件，不是本次已完成的測試結果。實作時以 ID 記錄 Pass、Fail 或 Blocked，附測試輸入、實際結果及必要截圖。

## 1 需求對照

| SDD 需求 | 驗收 ID |
| --- | --- |
| FR01 至 FR03 | C01、C02、V01、V02 |
| FR04 | D01、D02、D05 |
| FR05 | D03 |
| FR06 | D04、D05 |
| FR07、FR08 | D02、V03 |
| FR09、FR11 | O01 至 O05 |
| FR10 | V04、D06 |
| NFR01 至 NFR04 | V01 至 V05、O04 |
| NFR05 至 NFR07 | D05、S01、S02、O01、O02 |

## 2 內容與連結

- [ ] C01：姓名及帳號正確；自介沒有捏造年資、職稱或能力；精選作品有公開依據。
- [ ] C02：2 至 3 個作品各有用途與有效 Repo 連結；Demo 只能使用已核對網址；沒有 `#`、example.com 或測試資料。
- [ ] C03：README 導向正確目標，未覆蓋不屬於生成器的內容；聯絡資料由使用者提供或省略。

## 3 資料與算法

| ID | 測試資料或情境 | 預期結果 |
| --- | --- | --- |
| D01 | 101 個公開儲存庫，混入 fork、archived、其他 owner | 走完兩頁；三種不符條件者排除；專案、Stars、語言集合一致 |
| D02 | 2026-10-07 作為資料日，含跨年、零貢獻月份 | 區間 2025-11-01 至 2026-10-07；12 月桶總和＝日資料總和＝日曆總數；本月 partial |
| D03a | 連續 3 天含今日都有貢獻 | current 3，截至今日 |
| D03b | 今天 0，昨天及前天有貢獻，再前一天 0 | current 2，截至昨日 |
| D03c | 今天和昨天皆 0 | current 0 |
| D03d | 連續區段觸及期間起點 | 顯示「至少」，longest 標示期間內，不能標成生涯紀錄 |
| D03e | 日期跨 2 月 29 日、缺日、重複日 | 閏年日正確；缺日或重複日拒絕快照；不能用整數 YYYYMMDD 相減 |
| D04a | 語言 bytes 1、1、1 | 最大餘數法得到總和 100.0%，排序及平手規則穩定 |
| D04b | 7 種語言、空字典、全零 bytes | 前 5＋其他；空字典不造假；全零顯示空狀態 |
| D05a | 429、403 限流、500、timeout | 按規範重試及總時限，失敗保留快照，不寫零 |
| D05b | GraphQL HTTP 200 帶 errors；第二頁失敗 | 不發布部分資料，即使第一頁成功 |
| D05c | 帳號不存在、語言端點 404、無效數字 | 明確失敗；不以不存在等於零 |
| D06 | 圖片及 details 產生於同一 fixture | 所有關鍵數字、期間及名稱完全相符 |
| D07 | 今日資料取得途中跨 UTC 午夜 | 使用開始時捕捉的 T，不混用隔日日期和前日統計 |

實際 API 整合另外驗證：GitHub 可見貢獻是否含匿名私人數量、欄位完整性、查詢時間邊界。此結果決定最終公開註記，但不得暴露私人儲存庫明細。

## 4 視覺與相容性

- [ ] V01：GitHub 真實 README 在 320、375、768、1280 CSS px 沒有水平溢出；標題、數字、日期不裁切。
- [ ] V02：GitHub 明暗模式皆可閱讀；原生文字是正常文字，SVG 不依賴宿主 CSS；整頁結構與設計規範一致。
- [ ] V03：0、1、極大值、最長語言名稱及非拉丁字元都可正常呈現；月圖零起點，日曆格沒有錯位或漏月。
- [ ] V04：一般文字對比至少 4.5:1；重要圖形至少 3:1；圖片 alt、文字摘要、details 和鍵盤操作存在且正確。
- [ ] V05：每圖小於 100 KB、全部小於 600 KB；SVG 沒有 script、foreignObject、外部資源、亂碼及重複 ID。

## 5 更新與維運

- [ ] O01：PR 只執行唯讀檢查，沒有 secrets 可供不可信 PR 使用，也沒有推送步驟。
- [ ] O02：手動與排程更新共用流程；API 或渲染失敗時正式檔案逐位元不變。
- [ ] O03：只有生成檔進提交；兩次更新不互相覆蓋；遠端分支移動時停止，不強推。
- [ ] O04：固定 fixture、tokens、期間的兩次輸出相同；同日無資料或內容變化不產生時間戳提交。
- [ ] O05：能由上一個成功 commit 回復首頁與快照；恢復後可再次手動成功更新。
- [ ] O06：第一次上線可在個人首頁看到圖片；圖片快取刷新後仍為正確版本；排程確實已在預設分支啟用。

## 6 安全與輸入

- [ ] S01：輸入包含 `<script>`、引號、`&`、換行、Markdown 連結及 `javascript:` 時，文字正確跳脫或網址被拒絕。
- [ ] S02：生成檔、快照、log、workflow 與 commit 不含 token、環境變數全集、Email 或私人資料；只能寫入輸出白名單。

## 7 完成定義

所有 FR、NFR 都有對應結果。必測項目 Fail 時不得標為完成；Blocked 要寫明缺少的外部條件。正式發布後再以 GitHub 個人首頁驗證一次。測試案例使用合成資料，正式首頁只能使用成功取得並驗證的真實資料。
