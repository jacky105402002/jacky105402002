## 3 技術與方法

技術標籤依公開專案資料與使用者實際使用情況挑選，最多 6 項，分成開發、工具、方法等必要群組。不能從自動語言統計推論熟練程度，不能把儲存庫中某種語言出現一次就當主要專長。

方法區優先描述可連結到實際成果的做法，如工作流程文件、可重用工具或實作紀錄。尚無內容時省略區塊，不保留「Coming soon」空殼。

## 4 活動文字

統計區標題「GitHub 動態」。共用註記：

> 貢獻依 GitHub 可見資料計算；期間包含尚未結束的本月。語言占比按公開、未封存、非 fork 的自有儲存庫程式碼位元組統計，不代表熟練度。

動態日期及真實數字由產生器填入。卡片不得標為「即時」。Streak 必須附「截至今日／昨日」「期間內最長」與必要的「至少」。

現有已知入口是 [GitHub 個人首頁](https://github.com/jacky105402002)。Email、LinkedIn、個人網站與其他社群未提供，不自行搜尋或猜填私人聯絡方式。沒有聯絡資料時省略該區，維持 Repo 及 GitHub 原生 Follow 入口即可。

不阻擋本機開發的缺漏：自介可先用上述提案、作品以核對過的公開資料建立草稿、聯絡區省略。正式發布前核對自介是否符合本人、精選專案是否正確、所有連結是否可用。
