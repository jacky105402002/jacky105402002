## 已確認的方向

主色為薄荷青綠 `#48D6B0`，輔色為柔霧藍 `#85AEFF`；底色 `#101A22`，卡片底色 `#192833`，主要文字 `#E6EDF3`。採用清楚分區、圓角模組、克制的線條與充足留白。

設計適用於個人首頁 README 內的圖片。GitHub 原生導覽列、側欄、分頁與整頁背景不在客製化範圍。HTML 預覽展示設計語言，不能整份貼入 README。
